================================================================
GABRIELA
================================================================

FILE DI MIA RESPONSABILITÀ:

  include/
    structs.h       → definizione di tutte le struct del progetto
    defines.h       → costanti (dimensioni schermo, velocità, tasti)
    cub3d.h         → header principale con tutti i prototipi

  src/utils/
    error.c         → ft_error(): stampa "Error\n" + msg, libera, esce
    free.c          → ft_free(): libera tutta la memoria allocata
    utils.c         → funzioni di utilità varie

  src/parser/
    parse_file.c    → apre il file .cub, controlla estensione,
                      legge riga per riga, identifica gli elementi
    parse_textures.c → parsing NO/SO/WE/EA, verifica path esistente,
                       errore se chiave duplicata
    parse_colors.c  → parsing F e C con RGB, validazione [0,255]
    parse_map.c     → lettura griglia mappa, rilevamento posizione
                      e orientamento giocatore (N/S/E/W)
    validate_map.c  → validazione caratteri, controllo mappa chiusa
                      (flood-fill o check bordi)

  src/render/
    sprites.c       → rendering sprite con Z-buffer, supporto multipli

  Makefile          → già scritto

  BONUS:
    src/bonus/minimap_bonus.c    → mappa 2D in overlay
    src/bonus/doors_bonus.c      → porte apribili e chiudibili

  ASSET:
    textures/       → trovare/creare 4 texture XPM (N/S/E/W)
    maps/test.cub   → mappa di test valida e completa
